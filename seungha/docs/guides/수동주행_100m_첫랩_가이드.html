노트북에서 Jetson으로 SSH 접속하고, Jetson이 Arduino Mega에 안전한 직렬 명령을 보내 조향 서보와 ESC를 제어하는 첫 수동주행 안내서입니다. 목표는 “빨리 달리기”가 아니라 100 m 트랙 한 바퀴를 반복 가능하게 완주하는 것입니다.

02 / SAFETY FIRST

전원을 켜기 전
안전 회로부터 닫기

사진상 배선은 연결되어 있지만, “연결됨”과 “안전하게 검증됨”은 다릅니다. 아래 항목을 멀티미터와 회로도 기준으로 확인합니다.

A

전원 분리

  • 구동 모터/ESC 전원과 Jetson 전원은 분기합니다.
  • 조향 서보를 Mega의 5 V 핀에서 직접 급전하지 않습니다.
  • 외부 BEC와 ESC 내장 BEC를 같은 5 V 레일에 무작정 병렬 연결하지 않습니다.
  • 신호 기준을 위해 Mega·서보/ESC 제어 GND는 공통으로 둡니다.
B

정지 계층

  1. 물리 비상정지: 모터 전력 또는 ESC enable 차단
  2. Mega kill 입력: 단선도 정지로 인식하는 NC 방식 권장
  3. Mega watchdog: 300 ms 명령 없음 → 중립
  4. Jetson dead-man: 키 반복이 끊기면 중립
중요: ESC가 어떤 펄스에서 전진/후진/브레이크하는지 모르는 상태에서는 바퀴를 지면에 놓지 않습니다. 일반적인 1500 µs 중립도 “가설”일 뿐이며 해당 ESC 설명서와 실측 반응으로 확정해야 합니다.

05 / MEGA FIRMWARE

중립으로 시작하고
통신이 끊기면 중립으로 끝내기

아래 스케치는 예시 핀과 좁은 임시 펄스 범위를 사용합니다. 실제 배선·서보·ESC 값으로 수정한 뒤 업로드해야 합니다. Mega의 D22는 NC kill 회로가 GND로 당길 때만 주행 허용 상태가 됩니다.

업로드 전 수정: `STEER_PIN`, `ESC_PIN`, `STEER_*_US`, `ESC_NEUTRAL_US`, `ESC_CRAWL_MAX_US`를 실차 기준으로 바꿉니다. D22–GND 점퍼는 바퀴를 띄운 벤치 시험에서만 임시 사용하고, 지상 주행 전에는 물리 kill 회로로 교체합니다.
mega_manual_drive.ino
#include <Servo.h>

// ===== 반드시 실제 배선/실측값으로 수정 =====
constexpr uint8_t STEER_PIN = 6;   // 예시값
constexpr uint8_t ESC_PIN   = 7;   // 예시값
constexpr uint8_t KILL_PIN  = 22;  // NC 회로: SAFE일 때 GND

constexpr int STEER_MIN_US    = 1420;
constexpr int STEER_CENTER_US = 1500;
constexpr int STEER_MAX_US    = 1580;

constexpr int ESC_NEUTRAL_US   = 1500;
constexpr int ESC_CRAWL_MAX_US = 1560; // 첫 시험용 전진 상한

constexpr unsigned long WATCHDOG_MS = 300;
constexpr unsigned long ARM_NEUTRAL_MS = 3000;

static_assert(STEER_MIN_US < STEER_CENTER_US &&
              STEER_CENTER_US < STEER_MAX_US,
              "Steering pulse order is invalid");
static_assert(ESC_NEUTRAL_US <= ESC_CRAWL_MAX_US,
              "ESC range is invalid");

Servo steering;
Servo esc;

char rxBuffer[48];
uint8_t rxIndex = 0;
unsigned long lastCommandMs = 0;
bool watchdogReported = false;
bool killReported = false;

bool killActive() {
  // INPUT_PULLUP이므로 회로가 열리거나 선이 끊기면 HIGH = 정지
  return digitalRead(KILL_PIN) == HIGH;
}

void forceNeutral() {
  steering.writeMicroseconds(STEER_CENTER_US);
  esc.writeMicroseconds(ESC_NEUTRAL_US);
}

void applyDrive(int steerUs, int throttleUs) {
  const int safeSteer = constrain(steerUs, STEER_MIN_US, STEER_MAX_US);
  // 첫 버전은 후진 금지: neutral보다 작은 값은 모두 neutral
  const int safeThrottle = constrain(throttleUs,
                                     ESC_NEUTRAL_US,
                                     ESC_CRAWL_MAX_US);
  steering.writeMicroseconds(safeSteer);
  esc.writeMicroseconds(safeThrottle);
  Serial.print("OK,");
  Serial.print(safeSteer);
  Serial.print(',');
  Serial.println(safeThrottle);
}

void handleLine(char *line) {
  int steerUs = 0;
  int throttleUs = 0;

  if (killActive()) {
    forceNeutral();
    Serial.println("STOP,KILL");
    return;
  }

  if (sscanf(line, "D,%d,%d", &steerUs, &throttleUs) == 2) {
    applyDrive(steerUs, throttleUs);
    lastCommandMs = millis();
    watchdogReported = false;
  } else if (strcmp(line, "PING") == 0) {
    Serial.println("PONG");
  } else {
    forceNeutral();
    Serial.println("ERR,FORMAT");
  }
}

void setup() {
  pinMode(KILL_PIN, INPUT_PULLUP);
  steering.attach(STEER_PIN);
  esc.attach(ESC_PIN);
  forceNeutral();

  Serial.begin(115200);
  delay(ARM_NEUTRAL_MS);  // ESC가 중립으로 부팅할 시간
  lastCommandMs = millis();
  Serial.println("READY,MANUAL_V1");
}

void loop() {
  while (Serial.available() > 0) {
    const char c = static_cast<char>(Serial.read());
    if (c == '\n') {
      rxBuffer[rxIndex] = '\0';
      handleLine(rxBuffer);
      rxIndex = 0;
    } else if (c != '\r') {
      if (rxIndex < sizeof(rxBuffer) - 1) {
        rxBuffer[rxIndex++] = c;
      } else {
        rxIndex = 0;
        forceNeutral();
        Serial.println("ERR,OVERFLOW");
      }
    }
  }

  if (killActive()) {
    forceNeutral();
    if (!killReported) {
      Serial.println("STOP,KILL");
      killReported = true;
    }
  } else {
    killReported = false;
  }

  if (millis() - lastCommandMs > WATCHDOG_MS) {
    forceNeutral();
    if (!watchdogReported) {
      Serial.println("STOP,WATCHDOG");
      watchdogReported = true;
    }
  }
}

06 / CALIBRATION

조향과 구동을
한 번에 시험하지 않기

먼저 조향 서보만, 다음에 ESC만 검증합니다. 두 액추에이터를 동시에 움직이면 기계 간섭인지 신호 오류인지 구분하기 어렵습니다.

1

조향 서보

  1. ESC 구동 전원을 차단하고 서보만 켭니다.
  2. 중앙 펄스를 적용해 타이로드 길이로 기계적 직진을 먼저 맞춥니다.
  3. 중앙에서 ±20 µs씩 천천히 넓힙니다.
  4. 타이어·링크·서보 혼이 닿기 전의 값을 소프트웨어 한계로 둡니다.
  5. 좌/우 명령 방향과 실제 바퀴 방향을 기록합니다.
2

ESC / 구동모터

  1. 조향은 중앙으로 고정하고 바퀴를 띄웁니다.
  2. 제조사 매뉴얼의 중립·arming 순서를 확인합니다.
  3. 중립에서 5–10 µs씩 전진 방향으로만 증가합니다.
  4. 바퀴가 안정적으로 도는 최초 값을 크롤링 값으로 기록합니다.
  5. Space, kill, USB 분리 정지를 각각 반복합니다.
하지 말 것: 모델을 모르는 ESC에 “1000–2000 µs 전체 범위 캘리브레이션”을 임의로 수행하지 않습니다. 일부 ESC는 후진·브레이크·설정 모드 진입 방식이 다릅니다. 제품 라벨을 확인해 정확한 매뉴얼을 먼저 찾으세요.

07 / KEYBOARD TELEOP

키를 계속 눌러야만
움직이는 수동주행

아래 Python 프로그램은 SSH 터미널에서 실행합니다. 마지막 운전 키 이후 0.35초가 지나면 자동 중립/중앙으로 돌아가며, Mega에는 20 Hz로 명령을 보냅니다. 역주행 명령은 없습니다.

W 크롤 전진 유지 A 좌회전 D 우회전 C 조향 중앙 Space 즉시 중립 Q 중립 후 종료
teleop_serial.py
#!/usr/bin/env python3
import argparse
import csv
import os
import select
import sys
import termios
import time
import tty
from datetime import datetime

import serial

# ===== Mega 펌웨어와 같은 실측값으로 수정 =====
STEER_LEFT_US = 1420
STEER_CENTER_US = 1500
STEER_RIGHT_US = 1580
STEER_STEP_US = 10

ESC_NEUTRAL_US = 1500
ESC_CRAWL_US = 1560

SEND_HZ = 20.0
DEADMAN_S = 0.35


def clamp(value, low, high):
    return max(low, min(high, value))


def send_drive(ser, steer_us, throttle_us):
    line = f"D,{steer_us},{throttle_us}\n"
    ser.write(line.encode("ascii"))


def read_key_nonblocking():
    readable, _, _ = select.select([sys.stdin], [], [], 0)
    return sys.stdin.read(1) if readable else None


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--port", default="/dev/ttyACM0")
    parser.add_argument("--baud", type=int, default=115200)
    args = parser.parse_args()

    if not sys.stdin.isatty():
        raise RuntimeError("SSH의 실제 터미널에서 실행하세요.")

    os.makedirs("logs", exist_ok=True)
    stamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_path = f"logs/manual_{stamp}.csv"

    steer_us = STEER_CENTER_US
    throttle_us = ESC_NEUTRAL_US
    last_drive_key = 0.0
    old_terminal = termios.tcgetattr(sys.stdin)

    with serial.Serial(args.port, args.baud,
                       timeout=0, write_timeout=0.1) as ser, \
         open(log_path, "w", newline="", encoding="utf-8") as log_file:
        writer = csv.writer(log_file)
        writer.writerow(["monotonic_s", "steer_us", "throttle_us", "event"])
        log_file.flush()

        time.sleep(2.0)  # Mega reset/ESC 중립 대기
        tty.setcbreak(sys.stdin.fileno())
        next_send = time.monotonic()

        print("W/A/D를 계속 눌러 주행, Space 정지, Q 종료")
        try:
            running = True
            while running:
                now = time.monotonic()
                key = read_key_nonblocking()
                event = "tick"

                if key:
                    key = key.lower()
                    if key == "w":
                        throttle_us = ESC_CRAWL_US
                        last_drive_key = now
                        event = "forward"
                    elif key == "a":
                        steer_us = clamp(steer_us - STEER_STEP_US,
                                         STEER_LEFT_US, STEER_RIGHT_US)
                        last_drive_key = now
                        event = "left"
                    elif key == "d":
                        steer_us = clamp(steer_us + STEER_STEP_US,
                                         STEER_LEFT_US, STEER_RIGHT_US)
                        last_drive_key = now
                        event = "right"
                    elif key == "c":
                        steer_us = STEER_CENTER_US
                        event = "center"
                    elif key == " " or key == "s":
                        throttle_us = ESC_NEUTRAL_US
                        steer_us = STEER_CENTER_US
                        event = "stop"
                    elif key == "q" or key == "\x03":
                        running = False
                        event = "quit"

                # 키 입력/SSH가 끊겨도 마지막 주행 상태를 유지하지 않음
                if now - last_drive_key > DEADMAN_S:
                    throttle_us = ESC_NEUTRAL_US
                    steer_us = STEER_CENTER_US

                if now >= next_send:
                    send_drive(ser, steer_us, throttle_us)
                    writer.writerow([f"{now:.3f}", steer_us, throttle_us, event])
                    log_file.flush()
                    next_send = now + (1.0 / SEND_HZ)

                    # Mega 응답을 쌓아두지 않고 마지막 상태를 한 줄로 표시
                    reply = ""
                    while ser.in_waiting:
                        reply = ser.readline().decode("ascii", errors="replace").strip()
                    sys.stdout.write(
                        f"\rsteer={steer_us:4d}  esc={throttle_us:4d}  {reply:24s}")
                    sys.stdout.flush()

                time.sleep(0.005)

        finally:
            # 정상 종료/예외 모두 여러 번 중립 전송
            for _ in range(5):
                try:
                    send_drive(ser, STEER_CENTER_US, ESC_NEUTRAL_US)
                    ser.flush()
                except serial.SerialException:
                    break
                time.sleep(0.05)
            termios.tcsetattr(sys.stdin, termios.TCSADRAIN, old_terminal)
            print(f"\n중립 종료. 로그: {log_path}")


if __name__ == "__main__":
    main()

mkdir -p ~/kmu_manual

python3 teleop_serial.py --port /dev/ttyACM0
운전 방법: SSH 터미널에서 프로그램을 전경 실행합니다. `tmux`, `nohup`, 백그라운드 실행은 첫 수동주행에 사용하지 않습니다. 키를 떼면 0.35초 후 중립이므로 W/A/D를 반복해서 눌러야 움직입니다.

바퀴를 띄운 fail-safe 검증

  1. W를 눌러 바퀴가 천천히 도는 동안 키를 놓습니다 → 0.35초 후 중립.
  2. 다시 W를 누른 뒤 SSH 창을 강제로 닫습니다 → Jetson dead-man 또는 Mega watchdog으로 중립.
  3. 다시 접속해 W를 누른 뒤 Mega USB를 뽑습니다 → Mega watchdog으로 중립.
  4. W를 누른 상태에서 kill 회로를 엽니다 → 즉시 중립.
  5. 각 항목을 10회 반복하고 실패가 한 번이라도 있으면 지상 주행 금지.
08 / TRACK VALIDATION

2 m에서 합격하고
100 m로 늘리기

첫 랩은 한 번의 큰 시험이 아니라 네 번의 작은 시험입니다. 단계마다 멈추고 로그, 조향, 정지거리, 커넥터 온도와 풀림을 확인합니다.

1

2 m

직진·Space 정지. 출발/정지 방향과 최소 속도 확인.

2

10 m

직선 3회. 좌우 쏠림, 정지거리, 통신 끊김 확인.

3

20–30 m

넓은 타원. 좌/우 회전반경과 복귀 조향 확인.

4

100 m

안전 담당자와 첫 랩. 속도 증가는 금지하고 완주에 집중.

현장 배치

DRIVER

노트북 운전자

차량을 직접 볼 수 있는 위치에서 키보드를 조작합니다. 화면 로그만 보고 운전하지 않습니다.

SAFETY

비상정지 담당

차량과 안전거리 내에서 물리 kill을 소지하고, 사람/장애물 진입 시 즉시 차단합니다.

BOUNDARY

통제 구역

주행로와 대기 구역을 분리하고, 코너 바깥쪽에 사람을 두지 않습니다.

09 / TROUBLESHOOTING

증상으로 원인을
빠르게 좁히기

증상가장 먼저 볼 것조치
Permission denied: /dev/ttyACM0groups, 포트 소유 그룹`dialout` 추가 후 SSH 완전 로그아웃/재로그인. sudo로 실행하지 않기.
포트가 매번 바뀜/dev/serial/by-id/고정 by-id 경로를 `--port`에 사용.
ESC가 계속 beep중립 펄스, arming 시간, 배터리매뉴얼 기준 중립 확인. 조향 시험과 분리.
전원 켜자마자 바퀴가 회전ESC 중립 가정 오류즉시 물리 전원 차단. 중립값/설정 재확인.
A/D 방향이 반대좌/우 펄스 상수Python의 LEFT/RIGHT 값을 교환하고 바퀴를 띄워 재시험.
조향 끝에서 윙윙거림기계 스토퍼·타이로드 간섭소프트웨어 펄스 범위를 안쪽으로 줄임.
모터 출발 때 Jetson 재부팅저전압, 공통 전원, DC-DC 여유구동/연산 전원 분기, 배선 굵기·커넥터·DC-DC 점검.
SSH 키 입력이 끊김ping 손실, Wi-Fi 혼잡주행 중단. 전용 공유기 위치·채널을 개선한 후 100회 재시험.
카메라/LiDAR 연결이 불안정USB 전력·대역폭첫 수동랩에서는 센서를 분리해 구동계부터 검증.
주행을 즉시 중단할 징후: ESC/커넥터 비정상 발열, 타는 냄새, 서보 지속 버징, Jetson 저전압 경고, 1회라도 발생한 fail-safe 실패, 조향 링크 풀림, 패킷 손실.

수동주행을 통과한 뒤
기존 자율주행 코드에 연결

현재 `kmu_track` 패키지에는 차선 인식, 신호등, 미션 매니저, 시각화 노드가 있습니다. 다음 구현은 이 인식 파이프라인을 바로 ESC에 연결하는 것이 아니라, 검증된 직렬 bridge 앞에 명령 mux를 두는 것입니다.

teleop / autonomy두 명령원
›
command mux수동 우선 · E-stop
›
mcu_bridge범위 변환 · heartbeat
›
Mega watchdog최종 안전 제한

먼저 추가할 노드

  • mcu_bridge_node: ROS 명령 → 직렬 D 메시지
  • teleop_node: 키보드 → 정규화 조향/속도
  • command_mux: 수동·자율·정지 우선순위
  • vehicle_state_node: ACK/watchdog/kill 상태 발행

유지할 안전선

  • Mega의 pulse clamp와 watchdog은 제거하지 않음
  • 자율 모드도 같은 크롤링 상한부터 시작
  • 수동 override와 물리 kill이 항상 최우선
  • 명령과 실제 상태를 rosbag/CSV로 기록

추천 단계

  1. 현재 Python teleop으로 100 m 3회 연속 완주.
  2. Python 로직을 ROS 2 `teleop_node` + `mcu_bridge_node`로 분리.
  3. 동일한 2 m → 10 m → 30 m → 100 m 회귀시험.
  4. 카메라 차선 오차를 기록만 하고 제어에는 사용하지 않음.
  5. 수동 override를 유지한 상태에서 저속 차선 유지 제어 추가.
  6. 마지막에 미션 FSM과 신호등/장애물 기능 연결.
왜 이 순서인가: 기존 인식 코드와 실제 구동계 사이의 인터페이스를 고정하면, 이후 차선/신호/FSM을 바꾸더라도 Mega 안전 계층과 조향·ESC 캘리브레이션을 다시 만들 필요가 없습니다.

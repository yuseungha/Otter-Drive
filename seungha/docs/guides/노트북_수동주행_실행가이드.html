노트북 수동주행 실행 가이드

노트북 브라우저 → Jetson ROS 2 → USB 시리얼 → Arduino → 조향/ESC 구조입니다.

현재 완료된 상태

  • Windows와 Ubuntu-22.04에서 ssh jetson-car 비밀번호 없는 접속
  • Jetson의 /home/sandi/ros2_ws에 laptop_teleop 배포 및 빌드
  • 브라우저 ARM·비상정지·0.25초 heartbeat 자동정지 검증
  • 제어 로직 단위 테스트 5개 통과
  • Arduino 포트: /dev/serial/by-id/usb-Arduino__www.arduino.cc__0043_5583832383535181C1B0-if00

1. 지금 바로 할 수 있는 DRY-RUN

  1. 탐색기에서 수동주행_드라이런.cmd를 더블클릭합니다.
  2. PowerShell 창을 닫지 않습니다.
  3. 브라우저가 열리면 실행 모드가 DRY-RUN인지 확인합니다.
  4. 안전 확인 체크 → ARM → W/A/S/D → Space 비상정지를 시험합니다.

DRY-RUN은 Arduino 시리얼을 열지 않으므로 모터가 움직이지 않습니다. 종료는 먼저 비상정지를 누른 뒤 PowerShell에서 Ctrl+C를 누릅니다.

2. 실차 실행은 현재 잠금 상태

수동주행_실차실행.cmd는 만들어져 있지만, 하드웨어 값이 확인되기 전에는 실행 스크립트와 Arduino 펌웨어가 모두 비영(非零) 출력을 차단합니다.

USB 장치는 VID 2341 / PID 0043으로 인식됐지만 사용자가 알려준 보드는 Mega입니다. USB 정보만으로 복제품까지 단정할 수 없으므로 보드 인쇄와 실제 배선을 확인해야 합니다.

3. 보내줘야 하는 확인 자료

항목현재 발견된 후보확인 방법
Arduino 보드Mega 2560 또는 Uno R3보드 전체 윗면 사진에서 MEGA/UNO 인쇄와 D22~D53 핀 존재 여부 확인
ESC signalD9ESC의 3선 신호 케이블을 따라가 꽂힌 숫자 확인
조향 ENAMega D8 / Uno D5 후보모터 드라이버 ENA에서 Arduino까지 선을 따라 핀 숫자 확인
조향 IN1·IN2Mega D22·D24 또는 D12·D13 후보모터 드라이버 IN1/IN2 선의 Arduino 핀 숫자 확인
조향 피드백Mega A0 또는 Uno A5 후보포텐쇼미터 신호선의 핀 확인. 필요 시 read-only probe 사용
조향 ADC좌 712 / 중앙 601 / 우 488 후보바퀴를 띄우고 좌·중앙·우에서 다시 측정
ESC 모델미확인ESC 라벨의 제조사와 정확한 모델명이 보이게 촬영

필요한 사진은 ① Arduino 전체 윗면, ② 핀 번호와 배선이 보이는 근접 사진, ③ ESC 라벨입니다.

4. 안전장치 구조

  • 브라우저: 20 Hz 명령 전송, 창 이탈·화면 전환 시 비상정지
  • Jetson 웹 노드: 0.25초 heartbeat timeout
  • ROS 시리얼 브리지: 0.30초 command timeout
  • Arduino 펌웨어: 0.40초 serial timeout, 조향 센서·방향·stall 검사
  • 초기 전진 제한 15%, 후진 제한 10%

5. 하드웨어 확인 후 첫 실차 시험 순서

  1. 구동 바퀴를 모두 지면에서 띄우고 사람이 차 앞뒤에 없는지 확인합니다.
  2. ESC 구동 전원을 즉시 차단할 담당자를 둡니다.
  3. 조향만 좌·우 10% 명령으로 방향과 피드백을 확인합니다.
  4. 전진 5%를 0.5초 이내로 시험하고 비상정지를 확인합니다.
  5. 통신 중단 시험으로 0.4초 이내 정지를 확인합니다.
  6. 지면에서는 보행 속도 이하로 직선 → 저각 조향 순서로 시험합니다.

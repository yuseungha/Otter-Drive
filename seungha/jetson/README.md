# Jetson 워크스페이스

이 폴더에는 실제 Jetson에서 가져온 ROS 2 워크스페이스와 장비 검증 기록을 둡니다.

현재 노트북에서 정리한 소스는 `../laptop/ros2_ws`에 있으며, Jetson 원본은 아직 이
폴더에 복사하지 않았습니다. `/root/ros2_ws` 또는 `/home/sandi/ros2_ws`에서 실제로
사용한 버전을 가져올 때 다음 원칙을 지킵니다.

- 소스는 `ros2_ws/src` 아래에 둡니다.
- `build/`, `install/`, `log/`, 모델, 영상과 장비별 승인 파일은 제외합니다.
- Jetson OS·ROS·Docker 환경과 검증 날짜를 함께 기록합니다.
- 노트북과 코드가 같아도 실제 배포본이라는 사실과 차이를 별도로 기록합니다.

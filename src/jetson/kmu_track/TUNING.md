# Lane steering tuning

이 문서는 `lane_drive_video.launch.py`의 화면을 보며 조정하는 순서를 정의한다. 기본 실행은 `enabled:=true`, `dry_run:=true`, `ignore_mission_state:=true`이며 실차 토픽에는 발행하지 않는다.

## 화면 판정 순서

1. FOLLOW VIEW에서 초록 측정점이 실제 흰색 선 위에 있는지 확인한다.
2. TARGET이 `BOTH_EDGES` 또는 `DASHED`인지 확인하고 장시간 `BOX`이면 지각 파라미터부터 조정한다.
3. STEERING 시계열에서 직선의 반복 부호 반전과 포화를 확인한다.
4. 제어 이득은 지각점이 안정된 뒤에만 조정한다.
5. `steering_sign`, 스로틀-속도 매핑, 실제 데드밴드는 실차 시험 전까지 확정하지 않는다.

## 안전 확인

- `dry_run:=true`에서는 `/rc_car/drive_cmd_preview`만 발행한다.
- `dry_run:=false`인데 `hardware_confirmed:=false`이면 노드가 기동을 거부한다.
- 실차 시험은 차량을 들어 올리고 조향 부호와 데드밴드를 먼저 확인한 뒤 접지 저속 시험으로 넘어간다.
- 주행 중 stop 요청은 throttle을 즉시 0으로 만들되, 속도 정지 확인 또는 fallback 지연 전에는 조향을 급센터링하지 않는다.

## 좌우 조향 실측표

현재 값은 하드웨어 미연결 상태이므로 확정하지 않았다. `0`은 기존 공통값
폴백이며 임의 보정값이 아니다.

| 측 | 이론 부호 | 펌웨어 8-count 경계 | 실측 데드밴드 | ADC/1000 | 정착시간 | 상태 |
|---|---:|---:|---:|---:|---:|---|
| LEFT | `+` | `+73` | - | - | - | 미검증 |
| RIGHT | `-` | `-62` | - | - | - | 미검증 |

상세: 활성 펌웨어의 Arduino `map(command, -1000, 0, 488, 601)`은
정수 나눗셈 기준점이 `-1000`이다. 따라서 `-70`은 ADC 594가 아니라 593이며,
우측 이론 이동 경계는 프롬프트의 `-71`이 아니라 실제 코드 기준 `-62`다.
실차 확정값은 각 측 3회 스윕의 중앙값에 안전 여유를 적용한 뒤 기록한다.
